## 4. Asset Recording Requirements

Before adding another third-party asset, record:

- Project asset name
- Original asset name
- Original author or publisher
- Original source page
- License name
- License reference
- Whether attribution is required
- Whether modification is allowed
- Project usage location
- Any renaming, conversion, editing, or import-setting changes

Do not commit assets with unknown origins, unclear licenses, or terms that
prohibit redistribution through a public GitHub repository.

When an original license file is supplied with an asset, preserve a copy with
the project documentation.
