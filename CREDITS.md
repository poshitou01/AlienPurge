## Recording Requirements

Before adding any third-party asset, record:

- Asset name
- Author or publisher
- Original source URL
- License name and license URL
- Whether attribution is required
- Whether modification is permitted
- Location where the asset is used in this project

Store third-party packages under:

`Assets/_Project/ThirdParty/<AssetOrPackageName>/`

When supplied by the author, keep a copy of the license file with the imported asset.

Do not commit assets with unknown sources, unclear licenses, or terms that prohibit redistribution in a public GitHub repository.
