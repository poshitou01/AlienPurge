本次方案与实现

爆炸：正式八帧火焰动画、短促亮芯、细火花、渐隐冲击波和少量残烟，持续 0.38 秒。
火焰复用项目中 Exploder/Explosion 的八张已完成资源；没有修改原 PNG、.meta、敌人 Prefab 或能力配置。
玩家效果有独立 Prefab，火焰大小按真实爆炸半径缩放，外层冲击波不超过该半径。

闪电：带变化的折线电弧、白色亮线与蓝色辉光、短分叉、目标命中光点。
各跳使用子弹实际命中的两个端点；每跳画面错开 18 毫秒，伤害仍在原来的时刻结算。
每段持续 0.20 秒，加上该跳的短延时；不会留下长时间遮挡战场的电线。

声音：独立的短爆裂与电击音效，使用原生主音量 / SFX 音量。
总共四个声部，两种声音分别限频；同一条闪电只在第一跳发声。

范围、伤害和组合规则保持原实现：
  爆炸 Lv1 / Lv2 / Lv3 半径 1.4 / 1.7 / 2.0，附加伤害比例 0.40 / 0.55 / 0.70。
  闪电 Lv1 / Lv2 / Lv3 跳数 1 / 2 / 3，每跳范围 3.5，附加伤害比例 0.60。
  雷电穿刺、集束爆裂的额外修正仍由已有 WeaponEvolutionData 和子弹快照决定。
  未增加特效伤害、额外结算、按生存时间解锁或新的刷怪系统。

对象池与隔离

继续使用场景原有的 ExplosionEffectPool / ChainLightningEffectPool。
集成场景预热 24 个爆炸和 64 段电弧，禁止自动扩容；满载时省略多余画面，伤害和经验不受影响。
网格、火焰渲染器与声部预先创建，复用时重置尺寸、端点、闪烁相位和动画帧。
暂停和升级选择时隐藏效果、停掉短音效；恢复时继续剩余画面。
死亡 / 胜利时回收活动效果；Restart 销毁上一局实例并重新预热。
旧场景未加入 UpgradeEffectVisual，仍使用原有圆圈 / 直线表现及持续时间。
