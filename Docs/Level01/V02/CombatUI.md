# V02 后期战斗与界面修订

继续在 `D:\AlienPurge_RegionLoopV01`、`feature/level01-region-loop-v02` 修改同一个 `Level01_FullWorld_GameplayV02.unity`。本次按新的试玩要求调整 HUD 外观，替代上一轮“仅改文字、保护 V01 任务面板布局”的限制。共享美术、仓库 / 背包 / 商店界面及其原资源不修改。

## 后期战斗

原配置普通敌人的基础生命在后段停留于 7；现在 V02 的新敌人按所在区域和玩家等级计算出生属性。

- 生命倍率：`min(7, 1 + 区域序号 × 0.24 + 超出6级的等级 × 0.14 + 超出6级的等级² × 0.0035)`，等级最多按 30 计算。区域序号从入口 0 到撤离 5。
- 后续区域的开门守卫额外乘 1.25，仍受 7 倍上限约束。隔离区普通敌人在 15 / 25 级分别为 23 / 40 生命；基础为 7。
- 移速增幅最多 22%。隔离区之后，普通敌人在 12 级、特殊敌人在 18 级后增加 1 点接触伤害，不随等级无限加伤。
- 增援属性在首次出生时确定；提前准备且未交战的驻守在玩家首次进入时定档，避免沿用开局的低等级。交战后随该敌人的归属记录保留，升级、离区再回来或对象池回收不会让它突然回血、提升最大生命。
- 后段混合小队新增 3 普通＋2 冲锋的追击组合；重型同时上限从 1 提到 2，特殊敌人合计最多 5。人口目标随等级和区域最多增加 6，隔离 / 研究 / 撤离区域上限分别为 32 / 34 / 26，全局仍为 56。
- 风暴、任务容量预留与补给间隙继续生效，击杀经验保持原值，不通过额外经验造成无限成长循环。旧场景与 Boss 对象池借用不启用这套成长。

调参入口是 V02 场景 `Level01_RegionLoop_V02` 上的 Combat / interface refinement 参数，以及独立区域配置。迁移用 `polishRevision` 标记，重复安装保留之后的手动调参和布局。

## 界面

复用 `Assets/_Project/Art/UI/Backpack/Sprites/` 下的 `Panel_Main_9Slice`、`Panel_Header_9Slice`、`Panel_Detail_9Slice`、`Panel_IconPreview_9Slice`，以及 Use / Discard 按钮的普通、悬停、按下、禁用状态。

- 底部三格：冲刺 / 跳跃 / 脉冲的独立图标、中文就绪状态、数字与遮罩冷却、固定键位。继续绑定原 PlayerAbilityHUD 与三个原生技能。
- 右上任务面板：标题、主要目标、倒计时与距离、进度、奖励、风险分行显示，使用深绿底板和金色边框；保留同一个 MissionHUD 与方向控制器。
- 任务箭头：用清晰的右向箭头几何替换 Bullet 图片，旋转仍由原控制器负责。靠近目标时沿用隐藏规则。
- 成功与失败：复用 GameManager 的真实结果快照和结算信息，显示行动时间、击杀数、最终等级与物资结果。按钮仍调用原 RestartGame / ReturnToBase；保存失败时显示重试保存按钮并禁用离开，避免把未保存物资显示成已入库。

`RegionResultPresentation` 只读结果数据；`RegionHudGlyph` 绘制小型 UI 图形。没有新增结算、背包或技能系统。
