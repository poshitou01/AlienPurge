# V02 玩家技能手感与主菜单修订

本轮在 `Level01_FullWorld_GameplayV02` 中安装 `PlayerAbilityFeel`，继续使用原有三个技能的状态、冷却与 HUD。未安装该组件的 V01 / Boss 场景保持原来的技能逻辑。

## 三个技能

| 输入 | 行为 | 默认配置 |
|---|---|---|
| Shift 冲刺 | 按移动方向快速推进，起段更快、末段收速；青白残影、速度线、短喷射声和轻震动；完整动作期间保护，结束恢复操作 | 0.16 秒、空地约 3.36 单位、冷却 0.85 秒 |
| Space 跳跃 | 接受输入当帧进入腾空并抬升视觉；可立即接管冲刺；保留空中移动和射击；落地恢复地面受击 | 腾空 0.58 秒、高度 0.85、冷却 1.35 秒 |
| Q 震荡脉冲 | 立即伤害并击退近身敌人，清除可见范围内的敌方投射物；双层冲击波和更低沉的释放声；重型敌人击退减弱 | 半径 3.8、动作 0.12 秒、冷却 5.5 秒 |

Q 伤害为 `3 + floor((等级 - 1) × 0.45) + floor(武器伤害 × 0.5)`，上限 28。敌人使用原生 `EnemyHealth.TakeDamage`，敌方子弹使用原生对象池回收；同一个敌人的多个碰撞体只结算一次。环境遮挡会阻止脉冲穿墙命中和清弹。

空格闪避普通接触、Fast 冲锋、Heavy 地面冲击波，以及原本就检查腾空状态的 Boss 地面波。远程弹、毒雾、风暴和未标记为地面攻击的 Boss 攻击仍然有效。

输入使用 180 毫秒缓冲，覆盖即将结束的冷却和动作。Q 的前 60 毫秒保留动作承诺，随后空格 / 冲刺可接管。缓冲超时、暂停、角色死亡或组件关闭时清理，不会在几秒之后突然补放技能。没有全局慢动作或时间冻结。

冲刺使用刚体扫掠检查环境；冲刺 / 腾空期间暂时忽略附近敌人的实体碰撞，结束恢复。特效对象预先创建并复用，技能动画结束后消失。音效复用工程已有的三个技能 WAV，独立音源调整音高和混音，遵守主音量与 SFX 音量；不会改变枪声或音乐的音高。`feedbackVolume` 和 `cameraFeedback` 可在组件中调整。

## 主菜单与安装

正确入口为 `Assets/_Project/Scenes/MainMenu_DeskV1.unity`。它已加入 Build Settings 首位；开始按钮进入 V02，V02 结算 / 暂停菜单返回 DeskV1，音乐也识别这两个场景。

这是对原保护清单的一项明确例外：仅修改 DeskV1 中现有 `gameSceneName` 的值。验证时将该字段还原为原值后核对原始 Git blob，菜单其余字节、所有源场景、共享 prefab、美术与 Boss 资产仍受原始基线保护。没有改写基线文件。

安装：`AlienPurge > Gameplay > Level01 > Install Region Loop V02`。安装器只对低于当前技能修订号的场景写入默认参数，后续重装保留手动调整的技能参数。无需给其他场景的 Player prefab 加组件。

调参位置：冲刺速度 / 时长 / 冷却在 `PlayerDash`，跳跃高度 / 时长 / 冷却在 `PlayerJetJump`，Q 的半径 / 冷却 / 动作时长在 `PlayerPulseSkill`；本轮 Q 的基础伤害 / 成长 / 击退及输入缓冲、音量、震动在新增的 `PlayerAbilityFeel`。

验证菜单：`AlienPurge > Gameplay > Level01 > Run V02 Ability and Menu Checks`。报告保存在 `AbilityChecks.txt`；截图为 `Abilities_Dash.png`、`Abilities_Jump.png`、`Abilities_Pulse.png`。测试使用独立存档，使用与键盘相同的请求入口、原生物理 / 受伤 / 对象池 / 菜单回调；测试场地、血量、等级与目标敌人是受控夹具，不能替代人的完整游玩与听感评估。
