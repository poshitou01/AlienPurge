# Level01 V02 战斗反馈修订

本轮在原有反馈之上强化击杀的辨识度，并按最新反馈恢复左上角的四枚状态图标。场景仍为 `Assets/_Project/Scenes/ArtTests/Level01_FullWorld_GameplayV02.unity`，主菜单仍为 `MainMenu_DeskV1`。

## 本次变化

- **普通命中**：短促的接触声、白色命中标记、敌人身体的短暂视觉反冲，以及读取真实 HP 的临时血条。
- **击杀**：独立的双重碎裂声、低频冲击和短确认尾音；金色标记与碎片；敌人沿受击方向倒下、收缩并淡出。普通敌人单次击杀也会在技能栏上方显示“击杀确认 × 1”。
- **连续击杀 / 重型击杀**：连续击杀计数和小幅音高递进；重型敌人使用更低沉的音色、稍长的倒下动作和更明显的短镜头震动。

四个 WAV 为工程内可重现的原创程序音效，保存在 `Assets/_Project/Audio/SFX/Combat/ImpactV03/`。保留旧 ImpactV02 文件以便对比；新场景绑定 V03。这里没有增加护甲系统，提示准确表示命中、击杀或重型击杀。

## 为什么这次更容易感知

上一版普通击中与击杀共用相似的起音，击杀尾音很轻，单次普通击杀没有文字确认。本轮重做了击杀声音的结构，并将玩家枪声分到独立音源。击杀确认出现时，枪声短暂降低后恢复，音乐小幅让出空间；受伤、敌人危险提示、技能及 UI 音效保留原来的通道和音量。

普通击杀让枪声降到 40%，保持约 40 ms，随后在 140 ms 内恢复；重型击杀为 28%、70 ms、190 ms。两次强调有独立的 240 / 340 ms 间隔，密集击杀时也会让枪声恢复。用户音量设置不被临时混音改写；暂停、选升级、结束和切场景都会清理临时状态。

声音、金色标记、倒下动作来自同一次真实死亡。普通命中不能覆盖刚出现的击杀标记；群体伤害同帧只播放最高优先级确认声。前一个击杀声的尾部会降低音量，避免同时响成一团。

## 界面

左上角复用原有 HP、EXP、时钟和击杀图标，继续使用背包 / 仓库 / 商人同一套深色金边素材。去掉占空间的“战斗状态”标题，保留 **HP、EXP 英文**，等级置于独立小框。暖红血条、青绿色经验条和图标提供明确区分；低血量仍显示警示色。血量、经验、等级、时间和击杀数均通过原 `HUDManager` 更新。

实机截图：`Player_StatusHUD.png`、`Player_StatusHUD_Low.png`。击杀截图：`Impact_SingleKill.png`、`Impact_HeavyKill.png`、`Impact_KillConfirmation.png`。

## 边界与资源预算

原 `EnemyHealth` 继续处理伤害、死亡、经验掉落和击杀计数。视觉反冲不移动敌人的碰撞体，也不打断攻击；没有修改全局时间缩放。12 个固定死亡快照可以在敌人归还对象池后继续短暂呈现，不会改变新刷出的敌人。已有专用死亡动画的敌人和 Boss 保留其原生死亡表现。

命中特效为 24 组固定发射器，音效为 6 个固定音源；新增命中标记只有一个，且不拦截鼠标。屏幕外伤害继续正常结算，不制造屏幕内确认。SFX 与 Master 静音覆盖新声音和枪声通道。

## 安装和调参

场景已保存。重复安装入口：`AlienPurge → Gameplay → Level01 → Install Region Loop V02`。HUD 自己记录版本，不重新设置已调好的移动和持枪参数。安装时提前更新 TMP 子网格，避免中英文标签切换造成延迟的对象数量变化。

场景 `Level01_RegionLoop_V02` 上的 Combat Impact Feedback：

迁移只更新上一版默认音量和震动值，保留已经手动调整的不同数值。V03 WAV 已存在时安装器不会覆盖；生成配方在 `CombatImpactAudioAuthoring.cs`。

## 验证和试听

2026-10-18 本轮重新运行 138 项记录检查，全部通过：`ImpactChecks.txt` 45 项、`PlayerChecks.txt` 49 项、`AbilityChecks.txt` 44 项。覆盖真实连射单次击杀、群体命中优先级、移动镜头标记、静音、暂停、回池、HUD 大数值 / 低血量和 DeskV1 往返。安装器重复执行及受保护资产校验通过；`CombatUIChecks.txt` 保留此前的历史回归，本轮没有将其计入这 138 项。测试使用隔离存档，在实际 Unity Play Mode 中验证，退出后恢复项目设置；本轮没有生成独立可执行构建。

`Impact_SoundPalette.wav` 顺序为普通命中、强命中、普通击杀、重型击杀，使用默认游戏内相对音量。四个 PCM 文件为 48 kHz 单声道，峰值约 0.82，首尾为零；RMS 分别约 0.157、0.133、0.204、0.183。预览不包含音乐或实际交火的混音。自动验证覆盖逻辑、混音状态和画面；主观听感仍需在耳机或音箱中试玩判断。
