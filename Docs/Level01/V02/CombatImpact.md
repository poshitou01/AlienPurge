# V02 打击反馈

在 `Level01_FullWorld_GameplayV02` 中启用，主菜单仍为 `MainMenu_DeskV1`。

## 体验设计

命中先给出短促、清晰的接触声，敌人轮廓瞬间闪亮并沿受击方向小幅偏移；短暂显示的生命条直接读取真实血量，橙色尾条展示刚刚损失的部分。单次造成至少 20% 最大生命的伤害（最低 2 点），或受到 Q 冲击时，使用更厚的命中声和稍强的视觉反应。

击杀使用独立的碎裂声和短尾音，重型敌人击杀增加低频重量与更明显的碎片。普通命中不震屏，击杀只产生很短的轻微震动；同帧大量伤害优先播放关键结果。2.2 秒内连续完成至少 3 次屏幕内击杀时，左侧显示短暂的“连续击杀”计数。这个计数只有反馈意义，不修改伤害、经验或奖励。

项目没有护甲机制，因此没有“破甲”提示。这里参考的是关键战斗结果应当在声音上鲜明可辨的设计思路；四个 WAV 均由本项目的可复现合成代码制作，不含其他游戏的录音或采样。

## 实现与边界

- 普通子弹、穿透/分裂产生的子弹、爆炸、连锁闪电，以及 Q 的伤害统一经过 `CombatImpactFeedback.ApplyDamage`。生命扣除、死亡、掉落、击杀登记仍由原 `EnemyHealth` 完成。
- 仅 V02 场景安装反馈服务。没有该组件时，原生伤害与原音效/命中特效继续工作；读档、区域敌人血量恢复和调试扣血不会伪造玩家命中。
- 受击偏移由精灵副本短暂呈现，原精灵仍接收动画帧；包括精灵与碰撞体共用根物体的敌人，也不移动碰撞体、不暂停 AI、不产生无限硬直。Boss 保留自身的动作和受击表现，只接入统一音效与命中碎片。
- 24 组可复用命中碎片、6 个固定音源。普通命中间隔至少 75 ms，击杀至少 120 ms；同帧选择最高优先级事件，击杀期间压低普通命中声。碎片也优先保留击杀，同帧同位置的普通特效合并，避免叠成过亮光团。屏幕外敌人仍正常受到伤害，不播放本地击杀确认。
- 命中轮廓约 75 ms、视觉反冲 140 ms、血条 1.4 秒。暂停、选升级、结束游戏或敌人回池都会清理效果，不改变 `Time.timeScale`。
- 音效实时遵循现有 Master / SFX 音量，包括静音。声音有小幅随机音高和左右位置变化；使用独立随机源，不干扰刷怪/掉落随机序列。

## 调整与安装

场景 `Level01_RegionLoop_V02` 上的 **Combat Impact Feedback** 可调整：

| 设置 | 默认值 | 用途 |
|---|---:|---|
| Feedback Volume | 0.7 | 命中与击杀音量，之后再乘现有总音量/SFX 音量 |
| Camera Feedback | 0.65 | 击杀震动强度；设为 0 可关闭本套反馈的震动 |
| Minimum Hit Interval | 0.075 秒 | 连射与群体命中的声音密度 |
| Minimum Kill Interval | 0.12 秒 | 群体击杀合并密度 |
| Chain Window | 2.2 秒 | 连续击杀提示的有效间隔 |
| Show Health Bars | 开启 | 受击后的临时真实血条 |

使用菜单 `AlienPurge → Gameplay → Level01 → Install Region Loop V02` 可重复安装，保留已安装后的 Inspector 调参。验证入口为 `Run V02 Impact Checks`；音效生成配方位于 `CombatImpactAudioAuthoring.cs`，已有 WAV 不会被安装器覆盖。

`Impact_SoundPalette.wav` 按普通命中、强命中、普通击杀、重型击杀顺序预览，使用默认游戏内相对音量；实际连射还会受到优先级和合并规则影响。

## 验证

Unity 2022.3.62f3c1 中使用隔离存档进行了以下 Play Mode 检查，共 212 项通过（2026-10-18）。安装器重复运行、场景引用和受保护资产校验通过。

| 报告 | 通过项数 | 覆盖 |
|---|---:|---|
| `ImpactChecks.txt` | 35 | 真实子弹/连锁/爆炸/Q、重复击杀、回池、音频文件、40 次同帧命中、静音和暂停 |
| `AbilityChecks.txt` | 40 | 冲刺、跳跃、Q、原生伤害、DeskV1 菜单往返 |
| `CombatUIChecks.txt` | 89 | 区域敌人、成长、奖励、武器进化、风暴/毒雾、撤离与结算 |
| `PlayerChecks.txt` | 48 | 移动/碰撞、八方向持枪、瞄准射击、上方状态 UI |

实际游戏画面见 `Impact_StrongHit.png`、`Impact_HeavyKill.png`、`Impact_KillConfirmation.png`。四个音效的采样峰值约 0.82、首尾为零、RMS 为 0.076～0.113；它们使用独立预加载的 PCM 音频。自动检查能够验证逻辑和音频文件指标，最终主观听感仍应以耳机或音箱中的游玩体验为准。本次没有生成独立可执行构建。
