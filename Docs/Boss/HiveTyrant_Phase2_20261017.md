# Hive Tyrant：Riftwing 二阶段强化

本轮基于 `bd55e95`，只强化二阶段的招式、节奏和可读性。入场成长快照、生命上限、玩家升级、原生跳跃冷却、普通敌人全局属性保持原设计。

## 阶段差异

| 项目 | Phase I | Phase II / Riftwing |
|---|---|---|
| 横扫 | 7 米、120°，一次释放；前摇 1.15 秒；弧浪速度 8.5 | 同样的近身范围；两次分别锁方向的释放；前摇 0.85 / 0.8 秒；弧浪速度 10.5，紫金色边缘 |
| 地裂 | 3 条危险路段、2 个安全缺口、1 排波面；前摇 1.55 秒；速度 8 | 5 条危险路段、4 个安全缺口、连续 3 排波面；前摇 1.1 秒；速度 10.5；波次间隔 0.55 秒 |
| 孢子 | 3 次单发；每 0.75 秒标记一次 | 3 组成对齐射，共最多 6 枚；每组间隔 0.65 秒；一枚锁定当前位置，另一枚交替封住左/右侧 |
| 孢子预警 / 残留 | 1.3 / 2.2 秒 | 1.15 / 1.6 秒；落点锁定后不追踪，拥挤的落点更快恢复可走区域 |
| 召唤 | 目标 7 只；优先重型、远程；12 秒冷却，1.4 秒前摇 | 目标 10 只，上限 16；空间和类型上限允许时优先重型、远程、快速、远程；9 秒冷却，1.05 秒前摇 |
| 技能后摇 | 原始配置 | 原来的 65% |
| 横扫 / 地裂 / 孢子冷却 | 4.5 / 8 / 11 秒 | 原来的 78%，即 3.51 / 6.24 / 8.58 秒 |
| 技能间空档 | 0.55 秒 | 0.22 秒 |

冷却就绪不代表强行释放：实际出招仍需满足距离、可达路线、动作占用和地面技能互斥。召唤可与已释放的地面技能并存；横扫、地裂与孢子不互相封住对方的安全路线。

## 开场与应对

二阶段沿用已有三秒变身动画与 Riftwing 提示。变身清理旧技能后，AI 优先召集虫群，再尝试三连地裂；若场地条件不允许，仍会选择其他合法技能。之后继续根据距离、小兵数量、冷却和最近使用时间选招。

- **Twin Rift**：两次横扫之间仍保留至少 2.9 秒释放间隔，兼容原生 2.5 秒跳跃冷却。第二刀重新锁定方向并单独预警。更快的前摇和推进速度减少直线后退的容错。
- **Faultline Cascade**：预警用紫色路线和三重箭头表示连续波次。一轮三排共享同一个原点、方向和安全通道；进入缺口后保持位置，直到最后一排通过。不能跳过第一排后立刻回到危险路段。
- **Spore Crossfire**：每组两个圈同时锁点，计时环表示各自的引爆时刻。侧翼落点交替左右；被墙阻挡或越界的侧翼弹跳过，不偷偷移到另一侧。应朝仍开放的方向持续移动。
- **Brood Rally**：更多远程单位配合快速单位分散玩家注意力，仍使用原生寻路、攻击和对象池；总召唤预算 64 不变。

HUD 保留现有爪形血条和美术，仅按新招式更新应对提示。技能不移动玩家或 Boss，不扩大镜头取景，也不添加受击震屏。

## 实现与保护

地裂计划在施法时记录阶段参数，所有波次共享经过真实 Player 碰撞体检查的通道。至少一条路线需在实际前摇和传播时间内可走到；封死路线时取消该次地裂。每个波面独立记录命中玩家，同一波的多段、多帧和多个碰撞体不会重复扣血。连续检测会处理一帧内跨越多个波次的情况，并把延迟波次的出生时间纳入玩家运动插值。

地面波和残留特效独立于身体收招存活。死亡、禁用、离场和重开取消排队中的后续波次。特效扩展为五个预分配地裂网格，不为十五个危险波段创建十五组 GameObject；孢子继续使用已有六槽池。横扫、孢子在释放时记录自己的速度/计时，不通过修改共享配置资产切换阶段。
