# 本轮实际渲染验收（2026-10-17）

结论：**身体动作已接入，正式视觉验收未通过；不能据此称 Hive Tyrant 制作完成。**

检查的是 Unity DX11 Play Mode 渲染，不是生成式效果图。`PoseAtlases/` 的 27 张图覆盖 9 个动作/阶段组合、3 个关键位置、8 个方向。排列为 D / DR / R / UR，下一行为 U / UL / L / DL。这些是受控姿态/镜头采样；它们证明真实渲染结果，不等于逐方向完整实时战斗录像。`DR_Sweep/` 的 25 帧与 `DR_Sweep_PlayMode.gif` 则来自一次实际调度的扫击，约每 0.08 秒采样。

方法迭代到 PoseLibrary authoringVersion 8：逐方向关节/多边形 → 连续权重 → 刚性三角片 → 逐像素透明连通分区。连续权重会拉伸硬甲；刚性片保住甲壳形状，却暴露原单层图中被前臂遮住的后肢/躯干。连通分区移除了部分误选碎片，但无法恢复原图没有的遮挡区。现有源文件是合成后的 PNG；本轮未得到通过验收的独立补全层。新图像生成单姿势样例也因比例/肢体一致性失败而拒收，没有批量生成失败素材。

已实际满足：原 PNG、中心 pivot、256 PPU、VisualRoot 场景比例及静态阴影保留；使用各自八方向原图；动作期间不叠加原来的静态手臂；两阶段均有真实肢体位移；伤害/释放 FX 仍由同一 Combat 调度；RiftWing 受击/死亡使用 Phase2 源图。

尚需满足：独立的干净前臂、后肢、躯干遮挡补全层，关节处无缺口的遮挡关系，以及由这些层支持的更充分死亡倒伏。当前关节参数和源拓扑记录可复用，但不能把其运行接入当作这部分已完成。72 项 CSV 全部保留并逐项记录此状态。

地面 FX 已查看实际 `Wave_Warning.png`、`Wave_Travelling.png` 和 `Level01_WaveWarning.png`：三段独立亮边/碎屑，两条空通道；未见粉色材质。截图由主相机 RenderTexture 获取，**不包含 Screen Space Overlay UI**，不能据此声称人工验收了用户血条外观。血条保护由序列化/文件校验记录证明。
