# AlienPurge Demo v0.1

这是当前已整合版本的 **Windows 64 位原样试玩包**。使用工程现有的主菜单和完整场景，玩法、地图、Boss、敌人、背包和界面保持制作前的集成版本。

## 启动

1. 完整解压 ZIP。
2. 双击 `AlienPurge.exe`，保留旁边的 `AlienPurge_Data`、`MonoBleedingEdge`、`UnityPlayer.dll` 和其他运行文件。
3. 在原有主菜单点击 **Start Game** 开始；**Settings** 调整现有音量设置；**Quit Game** 退出。

无需安装 Unity。不要在 ZIP 内直接运行，也不要单独发送 exe。

## 操作

| 按键 | 操作 |
| --- | --- |
| WASD / 方向键 | 移动 |
| 鼠标移动 | 瞄准 |
| 按住鼠标左键 | 连续射击 |
| 左 Shift | 冲刺 |
| Space | 喷射跃迁 |
| Q | 脉冲 |
| E | 靠近容器、终端或其他交互对象后使用 |
| Tab | 打开 / 关闭背包 |
| Esc | 关闭搜索或背包；正常行动时暂停 |

升级或核心选择时点击一张卡继续。容器需要等待搜索揭晓，然后点击物品收入背包。背包中可拖动物品、选中补给后使用。

## 推进和结束

按右上角提示清除开门守卫，再启用终端，推进殖民地入口、货运场、动力维护区、隔离生活区和感染研究区。普通增援不全部属于开门目标。击杀拾取经验升级，区域及任务奖励提供武器机制核心。风暴和毒雾沿用当前规则。

**本包保留当前集成版的 Boss 路线：完成研究 → 挑战 Hive Tyrant → 前往信标撤离。** 原集成版的撤离门仍要求击败 Boss，本次原样打包没有新增独立的提前撤离路线。

成功撤离或死亡后使用现有结算按钮重开、返回主菜单；退出游戏请在主菜单点击 Quit Game。暂停菜单也可返回主菜单。

## 存档

- 成功撤离的物资按当前规则存入仓库，仓库不足时进入待领取区。
- 死亡丢失本局携带物资，既有仓库物资保留。
- 每局等级、经验、模块和任务重新开始；没有中途存档。
- Demo 仅使用独立的应用名称保存数据，避免与开发工程 `AlienPurge` 的存档混用。

数据与日志目录：`%USERPROFILE%\AppData\LocalLow\DefaultCompany\AlienPurge Demo`

日志为 `Player.log`，存档为 `AlienPurgeSave.json`。不要通过删除存档来处理问题。

## 当前限制与反馈

此包按要求原样构建，没有额外制作 Demo 操作说明界面、显示设置界面或新结算按钮。源工程原有的测试组件和快捷键也保留，正常试玩请使用上面的操作键。具体构建检查、独立程序实测和未验证内容见《Demo_验收报告》。

首次启动可能会在 Unity 标志处等待一段时间。当前构建右下角保留 Unity 生成的 `trial version` 水印。

反馈时请附所在区域、操作步骤、截图和 `Player.log`，并说明 Windows 版本、显卡和分辨率。
