AlienPurge 隐私政策

更新日期：2026年10月20日

生效日期：2026年10月20日

AlienPurge 由个人开发者杨希磊运营（以下简称“我们”）。本政策说明我们在提供 AlienPurge 独立安装应用及受理用户反馈时如何处理信息，并说明您管理信息和联系我们的方式。联系邮箱：2729154744@qq.com。

本政策描述当前离线版本的功能。游戏无需注册账号，游戏业务功能没有自动上传存档、玩家操作记录或反馈附件的功能。设备上的本地处理、您主动发送的邮件，以及您另行使用的应用商店或操作系统服务，分别按下文说明处理。

1 信息的收集和使用

本地游戏数据。为保存游戏结果，应用在设备的应用数据目录保存游戏币余额、仓库物品及数量、物品摆放位置、待回收物品和存档版本，并保留用于恢复损坏存档的本地备份。游戏币仅为游戏内数值，不代表银行账户或支付信息。

本地设置和运行数据。应用在本地保存音量、画质、帧率、左右手操作布局、控件大小及透明度。运行时处理触摸和按键输入、屏幕尺寸及安全区域，并使用处理器、内存等运行环境信息完成显示适配和运行调度。引擎或操作系统可能在设备上记录启动、运行错误及崩溃诊断信息。

主动反馈。只有在您向联系邮箱发送邮件时，我们才会收到您的发件邮箱、显示名称、邮件正文、发送时间以及您选择附带的截图、日志或存档。我们仅将其用于回复、定位问题、处理投诉和履行相应法定义务。提交附件并非游玩条件；请先删除附件中与问题无关的个人信息。我们不会要求您为一般反馈提供身份证、密码或支付凭证。

当前游戏没有手机号注册、身份验证、支付充值、社交聊天、广告展示、个性化推荐或云存档功能，不会通过这些尚不存在的功能收集信息。本政策不把阅读、安装或继续游玩视为对将来新增信息处理行为的概括授权。

设备权限。当前 Android 离线安装包未声明 INTERNET 权限，也未申请相机、麦克风、定位、通讯录、电话、相册或通知权限。本地存档使用应用自己的数据目录，不需要读取您的照片或共享文件。iOS 应用同样不以访问上述敏感资源作为游玩条件。

2 信息的保存和期限

存档、设置和本地备份保存在您的设备中，供后续启动时读取；覆盖、删除应用数据或删除应用时，依操作系统规则处理。我们没有运营游戏云存档服务器，也无法远程读取、修改或代为恢复您未发送给我们的本地存档。

如果您启用了手机系统或电脑工具的备份、迁移、恢复功能，应用数据可能被相关系统服务备份或恢复。此类操作由您的系统设置和服务提供方管理，删除应用不等于删除所有系统备份。

您主动发送的反馈保存在运营者使用的 QQ 邮箱及处理该问题所必需的工作设备中，仅在处理反馈、争议及履行法定义务所需的最短期限内保存。目的已完成、保存已无必要或您的删除请求依法成立时，我们将删除或匿名化处理相关记录；法律要求继续保存的，仅为该法定目的保留。

3 Cookies 和同类技术

游戏为独立安装的应用，不使用浏览器 Cookies、广告追踪像素或跨应用跟踪技术提供游戏功能。本地偏好设置用于记住操作和显示选项，不用于广告画像。您自行打开的网页、邮箱或应用商店属于各自的服务环境，其 Cookies 及网络日志由相应服务提供方说明。

4 信息的共享转让和公开披露

我们不出售您的个人信息，也不将您提供的反馈用于广告投放或无关营销。发送邮件时，您和我们所使用的邮件服务商需要处理邮件的收发与存储；这不意味着游戏内嵌了邮箱 SDK。除完成您请求的服务、取得所需同意或法律法规允许的情形外，我们不向其他主体提供或公开您的个人信息。

如以后发生运营主体变更并涉及个人信息转移，我们会依法告知接收方及其联系方式，要求接收方继续履行信息保护义务；处理目的或方式发生变化时，依法重新履行告知及同意程序。

5 第三方组件和独立平台服务

Unity 游戏引擎及其本地运行组件用于画面、音频、物理、输入和设备适配。当前未接入 Unity 广告、付费、在线分析或崩溃上报服务；游戏中没有 TapTap 登录、TapSDK、广告归因或第三方统计 SDK 的业务接入。Unity 的一般隐私说明可在 https://unity.com/legal/privacy-policy 查阅，具体处理仍应以应用版本和实际启用的服务为准。

通过 QQ 邮箱与我们联系时，邮件的传输和存储由相应邮箱服务提供方完成。请同时了解所用邮箱的隐私规则。我们只在解决您反馈所需的范围内使用收到的内容。

您通过 TapTap、App Store、TestFlight 或其他渠道下载、测试、评价游戏，或使用系统备份、系统诊断共享功能时，相关平台可能依其规则处理账号、下载、测试反馈或诊断信息。这些属于您另行使用的平台服务；游戏业务代码不因此获得您的平台密码、支付资料或账号档案。您可在相应平台管理这些信息和授权。

隐私政策网页托管。本网页由 GitHub Pages 提供托管。您访问网页时，GitHub 会为安全目的记录和保存访问者的 IP 地址，无论您是否登录 GitHub。我们没有在本网页加入统计脚本、广告、追踪像素或收集信息的表单。网页访问与离线游戏存档相互独立，访问本网页不会上传您的游戏存档。有关托管服务的数据处理，请查看 GitHub 隐私声明及其 Pages 数据收集说明。

6 信息安全

我们按照最小必要原则处理信息，利用操作系统的应用数据隔离机制保存本地数据，并在处理反馈时限制不必要的复制和使用。当前本地存档并未单独加密，请您妥善保管设备，避免把存档、日志或含个人信息的截图公开分享。

如发生或可能发生个人信息泄露、篡改或丢失，我们将依法采取补救措施，并按适用要求通知相关用户和主管部门。我们不会以本政策免除依法应承担的责任。

7 您如何管理信息

查看和修改。您可以在游戏对应界面查看仓库、余额及回收内容，在设置中修改音量和移动端操作选项。当前没有游戏账号，因此不存在游戏账号注册资料或需要办理的游戏账号注销。

删除本地数据。Android 可在系统设置的应用管理中找到 AlienPurge，进入存储相关页面并选择清除应用数据；不同机型名称可能不同。iPhone 可在“设置—通用—iPhone 储存空间—AlienPurge”选择“删除 App”；“卸载 App”会保留文稿与数据。清除或删除后，本地游戏成果可能无法恢复。已有系统备份须另行在相应服务中管理。

反馈信息和权利请求。您可向 2729154744@qq.com 申请查阅、复制、更正或删除我们持有的与您有关的反馈记录，撤回基于同意开展的处理，或要求说明处理规则。我们通常通过原发件邮箱及必要的往来信息核验请求，不会要求无关的身份证明。撤回同意不影响此前依法开展的处理。

我们将在收到请求后十五个工作日内回复处理情况；不能立即完成或依法不能满足的，将说明原因及可行的后续方式。您也可以依法向履行个人信息保护职责的部门投诉，或通过法定途径维护权利。

8 未成年人信息保护

请未成年人在监护人指导下阅读本政策，并遵守实际发行渠道的适龄和使用要求。当前游戏没有要求玩家填写姓名、年龄或身份证的界面。请勿通过普通反馈邮件发送儿童身份证、照片等无关信息。

我们不会主动要求不满十四周岁的儿童提供个人信息。如因反馈需要处理相关信息，将依法取得监护人同意并采取相应保护措施；如发现未经适当授权收到了此类信息，将及时采取删除等措施。监护人可通过联系邮箱提出查询或删除请求。

9 政策更新

我们会根据应用功能和信息处理方式的变化更新本政策，并注明更新及生效时间。新增登录、实名认证、广告、联网统计、云存档等功能之前，我们会补充具体信息类型、用途、保存期限、接收方及权利行使方式，并依法履行告知、同意或其他必要程序。旧版本政策可通过联系邮箱申请查阅。
